Pooling benchmarking for PLMs

Independent research · Duke University School of Medicine

Protein language models encode a sequence as token embeddings, then a pooling step collapses those tokens into one vector for a prediction head. That pooling choice is usually a default, even though it decides which sequence information actually reaches the head.

This project is a benchmarking framework that treats pooling as an experimental variable. A single command-line entry point swaps the task, pretrained encoder, pooling method, LoRA rank, and seed while keeping training, evaluation, and logging the same.

The current task is protein fitness prediction: a regression problem on the FLIP GB1 split. The readout after pooling is a linear head. Evaluation is Spearman rank correlation on the held-out test set, with the best validation checkpoint kept for that comparison.

Backbones in the grid include ProtT5-XL, ESM2-650M, DPLM-650M, Ankh-base, ESM-plus-plus, and Profluent E1. Pooling families are mean, max, top-k (k = 5), light attention, sliced Wasserstein embeddings (SWE), and bag-of-mers (BoM; window 100, stride 20).

Each backbone–pooling pair is run as a linear probe (frozen encoder) and with LoRA fine-tuning at ranks 2, 4, and 8, with scaling α = 4r on the attention projection matrices. Training uses AdamW (learning rate 3×10⁻⁴, 20 epochs, effective batch size 128) and is repeated across three seeds. Runs are logged with the full hyperparameter set so pooling can be compared under matched conditions.

Subsurface sea temperature

ECE 661 · Computer Engineering Machine Learning and Deep Neural Nets · graduate-level

The model takes sea surface temperature, sea surface height, zonal and meridional surface wind, plus latitude and longitude, and predicts temperature at depth. Fully connected LSTM layers are replaced with convolutional ones so the network keeps spatial structure: convolutions use local neighborhood and sparse connections instead of flattening the map.

Experiments include ConvLSTM variants with sigmoid/tanh and sigmoid/ELU activations, the same stacks with a land mask, and a hybrid CNN–LSTM.

Pediatric CXR classification

ECE 685D · Introduction to Deep Learning · graduate-level

CLIP-style domain adaptation from adult chest X-rays to pediatric pneumonia vs. normal.

An image–text model is pretrained with contrastive loss on adult NIH CXRs, then the image encoder is fine-tuned on the Kermany pediatric set. At test time the image is classified by nearest text prompt (Normal / Pneumonia). That pipeline is compared with a pediatric-only ResNet trained with cross-entropy, and with two other adaptation methods: domain-adversarial training (DANN) and optimal-transport Wasserstein (sliced Wasserstein distance).

Learning curves report AUC and F1 against the fraction of pediatric data; evaluation includes ROC, precision–recall, calibration, and Grad-CAM.

Autonomous Vehicle TTC prediction

Independent research project

Time-to-collision as a risk score on nuScenes, using a frozen StreamPETR detector and a small MLP head.

Ground-truth TTC is built from a physics closure (distance over closing speed, capped at 10 s). A physics baseline runs that same formula on StreamPETR boxes and velocities. A learned head regresses seconds-to-collision from object query features, with and without explicit velocity embeddings, so the same detections yield both an interpretable baseline and a learned estimate.

On the trainval split, the physics baseline is strongest overall (MAE 1.48 s). Adding velocity to the MLP recovers most of the gap (MAE 1.71 s vs 3.57 s for query features alone). Short-horizon bins stay hard: nuScenes has almost no sub-second collisions, so the learned head has little supervision there. Built on StreamPETR (ICCV 2023).
