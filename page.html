Benchmarking Pooling Methods for Protein Language Models

Independent research · Duke University School of Medicine

Built a benchmarking framework for protein language models, which encode a sequence as token embeddings and then pool those tokens into one vector for a prediction head. That pooling choice is usually a default, even though it decides which sequence information actually reaches the head.

Treated pooling as an experimental variable: a single command-line entry point swaps the task, pretrained encoder, pooling method, LoRA rank, and seed while keeping training, evaluation, and logging the same.

The current task is protein fitness prediction: a regression problem on the FLIP GB1 split. The readout after pooling is a linear head. Evaluation is Spearman rank correlation on the held-out test set, with the best validation checkpoint kept for that comparison.

Backbones in the grid include ProtT5-XL, ESM2-650M, DPLM-650M, Ankh-base, ESM-plus-plus, and Profluent E1. Pooling families are mean, max, top-k (k = 5), light attention, sliced Wasserstein embeddings (SWE), and bag-of-mers (BoM; window 100, stride 20).

Each backbone–pooling pair is run as a linear probe (frozen encoder) and with LoRA fine-tuning at ranks 2, 4, and 8, with scaling α = 4r on the attention projection matrices. Training uses AdamW (learning rate 3×10⁻⁴, 20 epochs, effective batch size 128) and is repeated across three seeds. Runs are logged with the full hyperparameter set so pooling can be compared under matched conditions.
